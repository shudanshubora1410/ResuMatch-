How it works

Three steps. Nothing hidden in between.

Six categories, weighted per job, scored 0-100, then summed. Every point above is produced by code you can read - and the same inputs always produce the same number.

Step 1 Read both documents resume.pdf · DOCX · 41 KB → 6 sections, 18 keywords
Step 2 Score by fixed rules 40·80 + 25·84 + 15·80 + 10·80 + 5·40 + 5·100
Step 3 Show the working = 80.0 · 6 rule ids, one per category

A worked example, not a mock: those are the same six weights and six category scores the report above is showing. Change one input and the arithmetic changes with it - there is nothing else in the path from resume to number.
